# Codex Background Studio

一个面向 Windows 版 Codex 桌面端的可撤销背景图工具。它不修改 Codex 安装目录，而是在通过本工具启动 Codex 后，利用本机 Chromium 调试接口注入背景样式。

> 非 OpenAI 官方项目。Codex 更新可能改变内部页面结构，从而影响样式注入效果。

## 使用

1. 完全退出正在运行的 Codex（包括系统托盘中的进程）。
2. 双击 `start.cmd`。
3. 浏览器会自动打开控制面板；选择图片并调整参数。
4. 点击“启动 Codex 并应用”。控制面板运行期间会自动为新窗口重新应用背景。
5. 要恢复原状，点击“恢复原始界面”，再正常重启 Codex。

要求：Windows 10/11、已安装 Codex 桌面端、Node.js 22 或更高版本。

## 安全边界

- 仅监听 `127.0.0.1`，不向局域网开放。
- 图片与设置只保存在本机 `%APPDATA%\CodexBackgroundStudio`。
- 不写入 `WindowsApps`，不修改或替换 Codex 文件。
- 调试端口只绑定本机，并在 Codex 退出后消失。
- 程序不会上传所选背景图片。

Codex 更新可能改变页面结构；本工具使用尺寸和背景色启发式规则，尽量避免依赖内部类名。
